
# 🌟 Moda Y2K App

Una app web interactiva creada con Streamlit que explora las tendencias más icónicas de la moda de los años 2000.

## 📸 ¿Qué incluye?
- Imágenes por categoría
- Botón con curiosidades
- Música retro
- Fondo estilo collage Y2K

## 🚀 Cómo usar
1. Visítala online (si está publicada en Streamlit Cloud)
2. O ejecútala localmente:
   ```bash
   streamlit run moda_y2k.py
   ```

✨ *Revive los mejores looks del 2000 y déjate llevar por la nostalgia.*
